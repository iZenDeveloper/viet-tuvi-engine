# Security Policy

## Supported Version

The latest commit on `main` is the currently supported development version.
Published version support will be documented when the first package release is
created.

## Reporting

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/iZenDeveloper/viet-tuvi-engine/security/advisories/new).
Do not open a public issue for a vulnerability that could expose users,
execute arbitrary code, or compromise an integration.

Include the affected version, runtime, reproduction steps, impact, and any
suggested mitigation. Do not include API keys, credentials, or personal birth
data in the report.

Calculation disagreements without a security impact should use the calculation
bug or expert fixture issue forms instead.
